# 🏧 ATM Interface

A simple **Java Console-Based ATM Interface** developed using **Object-Oriented Programming (OOP)** concepts. This project simulates basic ATM operations such as depositing money, withdrawing money, and checking the account balance with PIN verification.

---

# 🚀 Features

* 💰 Deposit Money
* 💸 Withdraw Money
* 🔐 PIN Verification
* 📊 Check Account Balance
* ✅ Input Validation
* 🏦 Bank Account Management
* 🖥️ Console-Based User Interface
* 🔄 Menu-Driven Application

---

# 🛠️ Technologies Used

* Java
* Object-Oriented Programming (OOP)
* IntelliJ IDEA / Any Java IDE

---

```text
ATM-Interface

```

# 📌 Classes Overview

## 🏦 BankAccount

Handles all account-related information and banking operations.

### Data Members

* Account Number
* Account Holder Name
* Age
* Phone Number
* Balance
* PIN

### Methods

* Deposit Money
* Withdraw Money
* Check Balance
* Getters & Setters

---

# 🏧 ATM

Acts as the interface between the user and the bank account.

### Responsibilities

* Deposit Money
* Withdraw Money
* Display Account Balance

---

## ▶️ Main

The entry point of the application.

### Responsibilities

* Creates BankAccount object
* Creates ATM object
* Displays the ATM menu
* Takes user input using Scanner
* Performs requested operations
